# Eco Food Waste Reduction AI Agent

An intelligent web application that converts available ingredients into sustainable recipes with carbon footprint tracking and waste reduction strategies.

## Features

- **Recipe Generation**: AI-powered recipes based on your available ingredients
- **Carbon Footprint Tracking**: Calculates environmental impact of ingredients
- **Sustainability Scoring**: Rates recipes from 1-10 based on eco-friendliness
- **Portion Scaling**: Automatically adjusts quantities for any serving size
- **Waste Reduction Tips**: Practical advice to minimize food waste
- **Leftover Ideas**: Creative ways to reuse leftovers
- **Download Recipes**: Save recipes as text files
